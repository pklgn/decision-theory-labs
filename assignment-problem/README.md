# Задача о назначениях: размещение датчиков

Задача 14 курса «Теория принятия решений». Есть 4 датчика и 4 объекта; каждый датчик ставится ровно на один объект, на каждом объекте — ровно один датчик. Нужно найти раздачу с наименьшей суммарной ценой.

|          | объект 1 | объект 2 | объект 3 | объект 4 |
|----------|---------:|---------:|---------:|---------:|
| датчик 1 | 2  | 10 | 9  | 7  |
| датчик 2 | 15 | 4  | 14 | 8  |
| датчик 3 | 13 | 14 | 16 | 11 |
| датчик 4 | 4  | 15 | 13 | 19 |

Модель: F = Σᵢ Σⱼ cᵢⱼ xᵢⱼ → min, Σⱼ xᵢⱼ = 1, Σᵢ xᵢⱼ = 1, xᵢⱼ ∈ {0, 1}.

## Метод

Венгерский метод в пять шагов по Грешилову А. А. («Математические методы принятия решений», 2-е изд., 2014, § 3.5):

1. Редукция строк — вычесть из каждой строки её минимум.
2. Редукция столбцов — вычесть из каждого столбца его минимум.
3. Назначения по нулям — максимальное число независимых нулей (увеличивающие цепи, алгоритм Куна).
4. Если нулей не хватает — минимальное покрытие нулей линиями (теорема Кёнига), сдвиг на θ и возврат к шагу 3.
5. Выписать назначение; стоимость считается по исходной матрице.

Ответ проверяется полным перебором всех n! раздач.

## Запуск

Нужен .NET SDK (проект собран под .NET 10; для .NET 8/6 поменяйте `TargetFramework` в `Hungarian.csproj`).

```bash
dotnet run                  # матрица из условия
dotnet run -- matrix.txt    # своя квадратная матрица: строка — датчик, числа через пробел
```

## Результат

```
Шаг 5. Оптимальное назначение
   датчик 1 -> объект 3   c = 9
   датчик 2 -> объект 2   c = 4
   датчик 3 -> объект 4   c = 11
   датчик 4 -> объект 1   c = 4
   f(x) = 9 + 4 + 11 + 4 = 28

Проверка перебором: минимум = 28 — совпадает
```

Промежуточные шаги совпадают с ручным решением: после редукций нижняя оценка 26, на шаге 3 собирается только 3 независимых нуля, покрытие — строки 2, 3 и столбец 1, θ = 2, нижняя оценка 28. Жадный выбор минимумов дал бы 30.
